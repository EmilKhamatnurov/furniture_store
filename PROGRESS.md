### Главные расхождения кода с ТЗ

- Options пока JSON в `product_variants`; нет нормализованных справочников, unique combination constraints, typed DTO и made-to-order availability.

- Variant picker не отключает невозможные комбинации, не поддерживает query preselection и variant media.

## 2026-09-17 — Пересмотр визуального направления

Владелец выбрал направление **«Тихая архитектура / Material Modernism»** 17.09.2026. `Dark Atelier / Quiet Craft` заменено новым решением.

По коду текущий storefront выглядит аккуратно, но пока слишком похож на универсальный ecommerce-шаблон:

- тёплый кремовый фон + near-black + Playfair не дают бренду собственного характера;
- одинаковые rounded-карточки, pills и равномерная сетка делают композицию слишком предсказуемой;
- hero строится почти только на тексте и не показывает мебель как главный объект;
- текущий `DM Sans` загружается только с latin subset, поэтому кириллица может попадать в fallback-шрифт;
- документы уже требуют Prata + Manrope, а код ещё использует Playfair Display + DM Sans.

Утверждённое направление должно быть светлее `Dark Atelier`, но характернее за счёт асимметричной editorial-сетки, крупной материальной фотографии, более строгой геометрии и сдержанного цвета материала. Рабочая палитра: костяной/бумажный, графит, тёмный хвойный и глиняно-медный акцент. Этнические орнаменты и буквальный «локальный декор» не используются.

Следующая дизайн-задача: перенести токены и типографику в код, затем собрать homepage vertical slice на demo-контенте.

### Для фактической отправки уведомлений

В dev и production должен быть запущен отдельный worker (`npm run worker`) и заданы реальные `UNISENDER_API_KEY`, `EMAIL_FROM`, `EMAIL_FROM_NAME`, `ADMIN_EMAIL`. Без них заказ всё равно создаётся; worker не следует запускать для проверки почты до настройки провайдера, чтобы не исчерпать ограниченные retry-задачи.
