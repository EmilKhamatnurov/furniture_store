# SEO — задачи и чек-лист (KHAMATNUROV MEBEL)

Живой список того, что сделано и что предстоит по SEO. Рынок — РФ, значит
приоритет: **Яндекс** (Вебмастер, Метрика, Бизнес) и **Google** (Search Console).

## ✅ Уже сделано (в коде)

- [x] Шаблоны `title` / `description`, canonical на всех страницах
- [x] Open Graph + общая OG-картинка (`/opengraph-image`); статьи используют обложку
- [x] JSON-LD: Organization (логотип, адрес), WebSite + SearchAction, Product (Offer/AggregateOffer), BreadcrumbList, Article (author, publisher, image, wordCount)
- [x] `sitemap.xml` (товары, категории, статьи, страницы) + image-sitemap для статей
- [x] `robots.txt` (закрыты admin/account/cart/checkout/orders/api; Host; ссылка на sitemap)
- [x] Web-манифест + favicon (`icon.svg`)
- [x] Яндекс.Метрика (nonced-скрипт, включается по `NEXT_PUBLIC_METRIKA_COUNTER_ID`)
- [x] Мета-верификация Яндекс/Google (`YANDEX_VERIFICATION`, `GOOGLE_SITE_VERIFICATION`)
- [x] Блог: время чтения, автор, похожие статьи, RSS `/blog/rss.xml`, «последние» на главной
- [x] SSR / динамический рендер — контент виден краулерам без JS
- [x] Строгая CSP на nonce — не мешает индексации; корректные security-заголовки
